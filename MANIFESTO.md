# What this actually is

If you landed here from a search and you're confused: yes, it's a Boston slang
translator. And no, that's not really the point. Read this once — it's short.

## The bait and the payload

The **bait** is the slang. "Claude speaks Masshole" is funny, and the dictionary
is real, and if all you want is to turn your emails into chowdah-speak, help
yourself.

The **payload** is this: a huge number of smart, capable people — investors,
operators, finance folks, lawyers, anyone whose job lives in spreadsheets and
slide decks — are now expected to work with AI tools that run on **skill files,
markdown, and repositories**. Nobody ever taught them any of it. Editing a config
file feels like defusing a bomb. "Open a pull request" sounds like a medical
procedure.

So this is the lowest-stakes possible place to learn all of it. You already know
your hometown's slang cold — there is nothing to get *wrong* about the subject.
That strips away every ounce of intellectual risk and leaves only the mechanics:
fork a repo, edit a file, open a pull request, get reviewed, watch it merge. The
scary part, in isolation, wrapped in something fun.

**The dictionary is a set of training wheels. The bike is git.**

## The spirit — rules of the road

1. **You will feel dumb the first time. That's not a bug; it's the whole
   feature.** Everybody's first pull request is clumsy. Ten minutes later you've
   done the thing professional engineers do every day. The discomfort *is* the
   lesson doing its work.

2. **The joke is with people, never at them.** We laugh with the accent — plenty
   of us have it. We laugh with the guy who force-pushed to main. We never punch
   down at a neighborhood, a class, or an ethnic group. Whoever's running the bit
   goes first in the pratfall. (Full version: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).)

3. **Every word cites a source.** A link, or two locals who'll vouch. No source,
   no merge — a robot enforces it, no hard feelings. This is a dictionary, not a
   bathroom wall.

4. **Getting stuck and asking is allowed — encouraged, even.** It's a thing
   engineers do every single day. There's an "I'm stuck" issue template for
   exactly this. Using it is a sign you're doing it right, not wrong.

5. **Boston is the first city, not the only city.** The engine is
   region-agnostic. Yinzer, Philly, Baltimore, Minnesota, Cajun — all welcome as
   new data files. If your town talks funny, teach the robot.

## Where to start

- Just want to translate something? → [`SKILL.md`](SKILL.md)
- Want to add a word (your first PR)? → [`CONTRIBUTING.md`](CONTRIBUTING.md)
- Not ready to touch git yet? → open a "Suggest a word" issue and watch someone
  turn it into a PR. That's a free lesson in what a PR even is.

Welcome. Go break something small and harmless. That's how everybody starts.
